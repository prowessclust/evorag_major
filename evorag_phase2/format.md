# Major Project Report Format Guide

This project report is structured using LaTeX, split into multiple files for better organization. The main entry point is `main_report.tex`.

## File Structure & Organization

The report is divided into several `.tex` files, each representing a specific section. You should edit the individual files to add your content.

### 1. Main Entry Point: `main_report.tex`
- **Purpose**: This is the "brain" of your report. It includes all necessary LaTeX packages, sets the page layout (margins, headers, footers), and coordinates the order of all other sections.
- **Action**: **DO NOT** add your main project content here. Only edit this if you need to change global settings like the project title in the header (Line 53) or add new packages.
- **Compilation**: Always compile this file to generate the full PDF.

### 2. Front Matter (Preliminary Pages)
These sections use Roman numerals (i, ii, iii...) for page numbering.
- **`cover_page.tex`**: The title page. Edit this to include your Project Title, Batch ID, Names, USNs, and Guide's details.
- **`certificate.tex`**: The official certification of your work.
- **`acknowledgement.tex`**: Where you thank your guides, department, and others.
- **`CourseOutcomes.tex`**: Lists the learning objectives and outcomes of the project.
- **`abstract.tex`**: A one-page summary of your entire project.
- **TOC/LOF/LOT**: Automatically generated by `main_report.tex` based on your chapters and figures.

### 3. Main Content (Chapters)
These sections use Arabic numerals (1, 2, 3...) for page numbering.
- **`introduction.tex`**: Chapter 1. Introduce your project, its significance, and objectives.
- **`literature_review.tex`**: Chapter 2. Discuss existing work and papers you studied.
- **`technical_description.tex`**: Chapter 3. Detailed methodology, architecture, and implementation details.
- **`conclusion.tex`**: Summary of results and future scope.

### 4. Back Matter
- **`bibliography.tex`**: Your references and citations.
- **`appendix.tex`**: Extra material like code snippets, data tables, or raw results.

## Quick Tips for Editing
1. **Adding Figures**: Use `\begin{figure} ... \end{figure}`. The `main_report.tex` is configured to number them by chapter (e.g., Fig 1.1, Fig 2.1).
2. **Adding Tables**: Use `\begin{table} ... \end{table}`.
3. **Citations**: Ensure your references are added to `bibliography.tex`.
4. **Line Spacing**: The report is set to 1.5 line spacing as per standard requirements.
5. **No Placeholders**: Remember to replace all red/green/blue text in files like `cover_page.tex` with your actual project information.

## How to Compile
If you are using a LaTeX editor (like Overleaf, TeXmaker, or VS Code with LaTeX Workshop):
1. Open `main_report.tex`.
2. Click **Build** or **Compile**.
3. It will automatically pull content from all other `.tex` files.
